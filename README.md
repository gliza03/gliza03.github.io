# gabriellizam.com

My personal portfolio site, live at **[gabriellizam.com](https://gabriellizam.com)**.

- Bilingual: English and Spanish, with a switch in the nav (`?lang=es` opens the Spanish version)
- Plain HTML, CSS, and JavaScript, no framework or build step
- Responsive layout, light fall color palette, and reduced-motion support
- Hosted on GitHub Pages with a custom domain

Built with help from Claude Code.
